## Reflection
This lab proved more difficult than I had first assumed.

I underestimated how time-consuming certain parts would be, especially testing, documenting, and perhaps most of all, plotting.

The plotting functionality could definitely be improved, e.g. by using different colours for different shapes, adding corresponding labels etc., but I simply didn't have the time. On the other hand, the assignment didn't require it.

## About the lab

The purpose of this lab was to practise object-oriented programming (OOP) by creating classes for different geometrical shapes.

The project includes two abstract base classes, Shape2D and Shape3D, with Circle, Rectangle, Sphere and Cube as subclasses.

I also implemented a Shape2Dplotter using Matplotlib and tested the functionality with pytest (77 passed tests) and Jupyter Notebook.
